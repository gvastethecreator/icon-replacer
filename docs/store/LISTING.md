## English

### Product name

Icon Replacer

### Short description

Change and restore Windows folder and shortcut icons from a reusable local library and File Explorer context menus.

### Full description

Icon Replacer is a focused Windows utility for changing folder and `.lnk` shortcut icons without repeating the usual shell and `desktop.ini` setup by hand.

Import local `.ico` files into a reusable library, organize them into one-level collections, preview the result, and apply an icon from the management app or File Explorer. Icon Replacer creates a local restore record before supported changes so earlier icon choices can be reviewed and restored.

On Windows 11, packaged commands appear in the modern File Explorer context menu. A classic context-menu integration is also included for Windows 10 and the **Show more options** path.

The application is local-first. Imported icons, selected paths, shortcut metadata, `desktop.ini` information, and restore history stay on the device. No Icon Replacer account is required.

The Microsoft Store build relies on Microsoft Store for package updates and does not contact GitHub Releases when checking for updates.

### Features

- Change icons for folders and `.lnk` shortcuts
- Windows 11 modern File Explorer context-menu commands
- Classic Explorer context-menu support
- Reusable local `.ico` library under your Windows profile
- One-level icon collections
- Search and filter the icon catalog
- Preview before applying a change
- Local restore record created before supported mutations
- Recent-change history and restore workflow
- Validation for malformed or unsupported icon files
- Safe failure on protected or untrusted targets
- Normal per-user operation without automatic elevation
- Local-first storage without an Icon Replacer account

## Español

### Nombre del producto

Icon Replacer

### Descripción breve

Cambia y restaura iconos de carpetas y accesos directos de Windows desde una biblioteca local y el menú contextual de Explorer.

### Descripción completa

Icon Replacer es una utilidad para Windows que permite cambiar iconos de carpetas y accesos directos `.lnk` sin repetir manualmente la configuración del shell y `desktop.ini`.

Importa archivos `.ico` locales en una biblioteca reutilizable, organízalos en colecciones de un nivel, previsualiza el resultado y aplica un icono desde la aplicación o File Explorer. Icon Replacer crea un registro local de restauración antes de los cambios compatibles para poder revisar y recuperar configuraciones anteriores.

En Windows 11, los comandos empaquetados aparecen en el menú contextual moderno de File Explorer. También incluye una integración clásica para Windows 10 y la opción **Mostrar más opciones**.

La aplicación funciona de forma local. Los iconos importados, rutas seleccionadas, metadata de accesos directos, información de `desktop.ini` e historial permanecen en el dispositivo. No requiere una cuenta de Icon Replacer.

La versión de Microsoft Store utiliza Store para las actualizaciones y no consulta GitHub Releases al comprobar updates.
